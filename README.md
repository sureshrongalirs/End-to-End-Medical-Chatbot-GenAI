# End-to-End-Medical-Chatbot-GenAI

 Focuses on building a complete end-to-end medical chatbot using custom medical data and large language models (LLMs). The chatbot will be capable of providing responses related to diseases, medicines, and diagnoses. The project involves creating a knowledge base from a medical book, connecting it to an LLM, and developing a user interface for interaction. The implementation will follow a modular coding approach in Python, utilizing Git and GitHub for version control, and will eventually be deployed on a cloud platform.
